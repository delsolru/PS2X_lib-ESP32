# История изменений

Все заметные изменения **издания LROB.RU** библиотеки `PS2X_lib`.

Это производная работа от оригинальной **PS2X_lib 1.9** авторов Shutter,
Bill Porter, Eric Wetzel и Kurt Eckhardt
(<https://github.com/madsci1016/Arduino-PS2X/tree/master/PS2X_lib>),
распространяемой под GNU GPLv3. Всё перечисленное ниже — доработки LROB.RU
поверх оригинала; неизменённое поведение принадлежит авторам оригинала.
English version: [CHANGELOG.md](CHANGELOG.md).

## 2.0.0 — издание LROB.RU: порт на ESP32 (и любой другой MCU)

### Добавлено
* Работает на всём семействе ESP32 (ESP32, S2, S3, C3, C6), на ESP8266 и на любом
  другом ядре Arduino благодаря переносимой прослойке GPIO.
* Точные микросекунды на ESP32: задержки считаются по счётчику тактов CPU
  (`esp_cpu_get_ccount()`), а не через `delayMicroseconds()`, поэтому тайминг шины
  не зависит от частоты ядра и автоматически следует за `setCpuFrequencyMhz()`.
* `setTiming(clkLow, clkHigh, byteGap)` — перестройка скорости шины на ходу.
* Отчёт о состоянии: `lastError()`, `ok()`/`connected()`, `failedReads()`,
  `frameMicros()`, `lastOkAge()`, `errorText()`, `typeText()`.
* `debugPrint(Print&)` — дамп состояния без перекомпиляции с `PS2X_DEBUG`.
* `rawPacket()` / `rawPacketSize()` — доступ к сырому 21-байтовому ответу.
* Проверка корректности пинов → `PS2X_ERR_BAD_PIN` вместо молчаливого
  «контроллер не найден».
* Автоматическое восстановление при отключении/подключении геймпада (hot-plug) и
  при срыве в цифровой режим; отключается через `setAutoReconnect(false)`.
* `setReadDelay()` / `readDelay()`.
* `read_gamepad()` теперь возвращает `bool` (было `void`); старый код компилируется.
* README на английском и русском, полный текст GPLv3 в `LICENSE`, `library.json`
  для PlatformIO, пример `PS2X_ESP32_Diagnose`.
* Ещё шесть примеров под реальные задачи: `PS2X_TankDrive` (два коллекторных
  мотора, драйверы вроде L298N), `PS2X_ServoPanTilt` (сервоприводы с управлением
  скоростью, на ESP32 не нужна библиотека Servo), `PS2X_Calibrate` (калибровка
  стиков с сохранением в EEPROM/NVS), `PS2X_Telemetry` (поток CSV/JSON вместе с
  качеством связи), `PS2X_DualControllers` (два геймпада на одном MCU) и
  `PS2X_PressureRumble` (давление на кнопках + виброотдача).

### Исправлено
* Убраны AVR-специфичные `#include <avr/io.h>`, `SREG`, `cli()`,
  `portOutputRegister()`, `digitalPinToBitMask()` из общего пути — именно из-за них
  библиотека не собиралась на ESP32.
* `byte` / `boolean` заменены на `uint8_t` / `bool` в публичном API (скетчи,
  написанные под оригинал, компилируются без изменений).
* `bitSet()` заменён на обычный сдвиг (это макрос только AVR-ядра).
* На ESP32 линия DAT переведена в `INPUT_PULLUP`; оригинал полагался на
  `digitalWrite(HIGH)` на входе, что на ESP32 ничего не делает.
* `readType()` больше не печатает в `Serial` безусловно.
* Индекс в `Analog()` проверяется на выход за границы.
* Неудачный кадр больше не затирает состояние кнопок мусором.
* Первый хороший кадр после переподключения не рапортует обо всех зажатых
  кнопках как о «только что нажатых».

### Совместимость
* Имена класса, методов и констант, имя заголовка и структура файлов — как в
  PS2X_lib 1.9; существующим скетчам нужна только переустановка библиотеки.
